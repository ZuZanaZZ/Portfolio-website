My Portfolio

Automatontron

Automatontron is a logic game inspired by the Human Resource Machine game. In Automatontron, the player is tasked with constructing an automaton that recognises the language of the given level, and thus progresses in the game.

Automatontron card

Simple COBOL bank

This system simulates a simple exchange between a bank and its client. The user can choose between two clients. Then the amount to be transacted is selected. If there are sufficient funds in the user's account, the transaction will take place.

Simple COBOL bank card

ASP.NET To-Do Web Application (coming soon)

A web application built with the ASP.NET framework and written in C#. It will have a simple database of tasks. Users can create multiple to-do lists, add tasks to them, and delete them as needed.
