Simple COBOL bank

Simple bank simulation written in COBOL.

I have developed an interest in COBOL. I created a small simulation of a bank to practice the language. The project includes interaction between client and bank. The source code can be found on my GitHub

Functionality

Database of clients

System will ask you which client would you like to appear as. You can also add a new client.

Selecting a client

After selecting a client, their information is displayed. You'll be asked how much you'd like to transfer to the bank.

Adding a new client

If you selected that you'd like to add a client, you will be asked to fill out the client information. After that, you'll also be asked how much you'd like to transfer to the bank.

Transaction authorisation

Upon entering the transaction amount the program will check whether the account has sufficient funds. If the funds are available, the transaction will take place.

If not, the transaction is denied.
